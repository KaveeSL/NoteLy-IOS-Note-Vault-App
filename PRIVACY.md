# NoteLy privacy policy

NoteLy stores notes on your device. It does not create an account, and it does not send notes, search text, secret phrases, or encryption keys to a server. The app does not include analytics or advertising.

Everyday notes are stored in the app's local database. Private notes are encrypted on the device before they are written to disk. The phrase you choose is stored only as a salted hash in the iOS keychain. The encryption key is stored in the keychain for this device only.

Device backup of the encrypted files is off unless you turn that option on inside the private area. The key is still not included in the backup. An encrypted export file leaves the device only if you save or share it yourself. That file is encrypted with the password you choose for the export.

Face ID or Touch ID is used only to confirm it is you before private notes are unlocked. If biometrics are unavailable, the device passcode is used. The system prompt says "Unlock your notes."

You can delete everyday notes inside the app, erase the private vault from Settings, or delete the app to remove its local data.
